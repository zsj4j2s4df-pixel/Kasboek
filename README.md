# Kasboek

Een eenvoudig huishoudboekje als één zelfstandig HTML-bestand. Rekening en
contant worden apart bijgehouden, met vaste lasten, opnames, losse uitgaven,
spaarpotten, een wensenlijst en een kascontrole per maand.

## Gebruik

Open `index.html` in je browser, of zet de live versie op je telefoon.
Alle gegevens blijven **lokaal in je eigen browser** bewaard (`localStorage`);
er wordt niets naar een server gestuurd. Met de knoppen onderaan maak je een
back-up of zet je die terug.

## Online (GitHub Pages)

De site draait via GitHub Pages vanaf de `main`-branch. De laatste versie
staat op de Pages-URL van deze repository.
